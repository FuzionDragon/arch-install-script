# Arch Linux 

### Checklist (based on Arch wiki guide)
- Keymaps
- Encyption Option
- Password and Login
- Internet
- System Clock
- Disk Picker / Partitioning
- Disk Formatting
- Disk Mounting
- Root and Fstab
- Localization
- Time
- Network Config
- Root Password
- Bootloader (probably just Grub)

After the last step, reboot. From there, the user can run the config setup script (or run it from here as an option)
